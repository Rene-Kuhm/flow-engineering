# Architecture Decision Records

ADRs capture durable decisions that future maintainers and agents should not rediscover from chat history.

## Index

| ADR | Status | Decision |
|---|---|---|
| [0001](0001-lightweight-enterprise-governance.md) | Accepted | Keep enterprise governance lightweight and evidence-based. |

## When to add an ADR

Add an ADR only for durable architecture, operations, security, release, runner, memory, SDD, or public CLI decisions. Routine fixes belong in commits, tests, changelog entries, or incident notes instead.
