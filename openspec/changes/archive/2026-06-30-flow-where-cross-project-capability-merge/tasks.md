### T-4 — Verify Checks 2 + 3: paths exist + REQ-IDs exist

- **Goal**: Prove every cited `Source:` path resolves on disk AND every cited REQ-ID appears as a `### Requirement:` heading in the recovered delta (design §4 Checks 2 + 3).
- **Action** (exact — copy from design §4 Checks 2 + 3):
  ```bash
  # Check 2: every cited path exists
  paths=$(grep -oP 'openspec/changes/flow-where-cross-project-capability-merge/specs/cross-project-search/spec\.md' \
                openspec/specs/flow-where/spec.md | sort -u)
  fail=0
  for p in $paths; do
    [ -f "$p" ] || { echo "FAIL: missing $p"; fail=1; }
  done
  exit $fail

  # Check 3: every cited REQ-ID exists in the delta
  python -c "
  import re, pathlib, sys
  spec = pathlib.Path('openspec/specs/flow-where/spec.md').read_text()
  blocks = re.findall(r'^### (REQ-WHERE-[A-Z0-9-]+).*?\n(.*?)(?=^### |\Z)', spec, re.MULTILINE | re.DOTALL)
  fail = 0
  delta = pathlib.Path('openspec/changes/flow-where-cross-project-capability-merge/specs/cross-project-search/spec.md').read_text()
  delta_ids = set(re.findall(r'^### Requirement: (REQ-[A-Z0-9-]+)\b', delta, re.MULTILINE))
  for req, body in blocks:
      m = re.search(r'§(REQ-[A-Z0-9-]+)', body)
      if not m: print(f'FAIL: {req} has no §REQ-ID'); fail = 1; continue
      rid = m.group(1)
      if rid not in delta_ids:
          print(f'FAIL: {req} cites {rid} but delta spec does not define it'); fail = 1
  sys.exit(fail)
  "
  ```
- **Expected outcome**: both `exit 0`; 1 unique path (delta spec) exists; 6/6 REQ-IDs (`REQ-CROSS-PROJECT-SCOPE`, `REQ-DEFAULT-TEXT-FORMAT`, `REQ-EXPLICIT-FORMAT-FLAG`, `REQ-EXIT-CODE-MAPPING`, `REQ-ENGRAM-STUB`, `REQ-REGEX-OPT-IN`) found in delta at L17, L33, L52, L73, L93, L108.
- **Files affected**: `openspec/specs/flow-where/spec.md` + `openspec/changes/flow-where-cross-project-capability-merge/specs/cross-project-search/spec.md` (read-only).
- **Pre-requisites**: T-1 passed (delta spec SHA verified).
- **Acceptance criteria**: AC3 (each `Source:` path exists on disk), AC4 (each `Source:` REQ-ID exists in cited delta spec).
- **Risk notes**: design §4 Check 3 uses `\u00a7` (escape form of `§`); the bash command above uses literal `§` for readability. Both produce equivalent matches. If python is unavailable on Windows, fall back to `grep -c` per delta REQ-ID (6 greps total).
